# Noema

A persistent predictive cognitive architecture for learned agency.

Noema is an exploratory research project asking a first-principles question:

> Can we build a persistent system that understands and predicts a world first, then teach that system to talk?

The project does **not** assume that an LLM, tokenizer, SPM, or any current AI architecture belongs at the core. Those are candidate tools only if later evidence justifies them.

## Current status

Architecture brainstorming is in progress. No implementation architecture has been approved yet.

Current working material lives in `docs/working-design/`.
