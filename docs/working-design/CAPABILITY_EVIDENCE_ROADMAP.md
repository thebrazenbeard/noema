# Noema capability-evidence roadmap

Status: **BRAINSTORMING / EVALUATION ROADMAP / NOT AN APPROVED IMPLEMENTATION**

Level intent: **L1 capability coverage + L2 evidence discipline + L4 experiment sequencing.**

## Purpose

Noema now has many useful capability targets and many candidate mechanisms. The next risk is evaluating them in an order that accidentally lets one narrow benchmark define the mature architecture.

This roadmap therefore organizes **what the project must learn about Noema**, not the exact developmental curriculum Noema itself must experience.

It is an evaluator roadmap, not a fixed cognitive ladder.

## Global rule

Each stage asks a narrow question and should prefer the simplest candidate that passes under fair resources.

Passing one stage does not promote that stage's mechanism into the architecture for later stages.

A candidate advances only with its actual learned state carried forward where the test is meant to be developmental. Reset/reference variants may exist as diagnostics but cannot substitute for continual performance.

Across the roadmap, capability claims should use some combination of:

- acquisition after relevant experience;
- prequential/online prediction where applicable;
- intervention;
- transfer to changed surface form;
- ablation of the claimed learned mechanism or state;
- calibration/uncertainty behavior;
- negative controls;
- resource-fair baselines;
- resistance to catastrophic forgetting or destructive global revision.

## Gate 0 — information-boundary and attribution audit

Question:

> Do we know what information Noema actually receives and which capabilities are supplied by transducers/runtime infrastructure?

Before interpreting any later result, every learner-visible modality should have a transducer ledger describing:

- source;
- preprocessing;
- timing/provenance metadata;
- discarded information;
- introduced structure;
- whether the transformation is infrastructure or itself under evaluation.

Operator controls and diagnostics remain outside the learner-visible stream unless an experiment explicitly routes an observable consequence through normal channels.

Failure here invalidates later emergence claims because semantic leakage cannot be ruled out.

## Gate 1 — persistent online learning baseline

Question:

> Can the candidate maintain and revise useful state online at all?

Use simple non-semantic temporal systems before causal ambiguity or embodiment.

Required evidence:

- prediction improves from streaming experience;
- later behavior depends on earlier experience without replaying an external full transcript;
- learned state survives irrelevant intervening events;
- a regime change can be learned without wholesale loss of unrelated competence;
- a reset control loses the cross-time advantage.

This gate should be deliberately boring. If persistent online learning is unstable, higher-level cognitive experiments are premature.

## Gate 2 — uncertainty under observational ambiguity: Experiment A

Question:

> Can the candidate avoid false certainty when passive evidence is non-identifying, then revise appropriately from externally scheduled intervention evidence?

Use the existing Experiment A design.

Required evidence includes:

- good passive predictive performance without unjustified structural certainty;
- intervention-conditioned revision;
- held-out intervention prediction;
- surface-remapped transfer;
- local correction rather than destructive global rewriting;
- resource-fair comparison against continuous-only and reference structured baselines.

Important interpretation:

A candidate passing A has earned a narrow epistemic capability claim. It has not earned a claim that its representation is the mature Noema ontology.

## Gate 3 — active epistemic behavior: Experiment B

Question:

> Can Noema recognize when an available action is worth taking because it would resolve decision-relevant uncertainty?

Reuse A's world family so the new variable is intervention choice rather than a redesigned epistemic substrate.

Required evidence:

- selects informative interventions when their expected consequence matters;
- avoids compulsive information gathering when the result would not change a meaningful decision;
- retains uncertainty when no reachable evidence can resolve it;
- can stop deliberating and act robustly or defer under bounded resources.

This stage tests active evidence gathering, not generic curiosity as a designer reward.

## Gate 4 — model-family inadequacy / open-ended correction

Question:

> Can the learner recognize that its current representational family is collectively inadequate rather than crowning the least-bad available explanation?

Construct worlds in which the initially available candidate family cannot represent the generator well.

Required evidence:

- population/model-wide failure is behaviorally detectable;
- confidence does not simply concentrate on the least-wrong candidate;
- learning/search broadens or changes form under bounded resources;
- useful existing substructure is retained where still supported;
- a new representation or strategy materially repairs prediction/transfer;
- negative controls show that the learner does not enter perpetual global-search mode after ordinary noise.

No explicit `NONE_OF_THE_ABOVE` variable is required.

## Gate 5 — reusable skill, temporal abstraction, delayed credit

Question:

> Can Noema become more competent with repeated action, organize experience at useful temporal scales, and learn from consequences that arrive long after the implicated behavior?

Use the test ladder in `SKILL_TEMPORAL_CREDIT_FRONTIER.md`.

Required evidence should distinguish:

- genuine skill consolidation from permanent replanning;
- context-sensitive competence from cached action scripts;
- learned temporal chunking from evaluator-supplied episode boundaries;
- delayed credit from immediate reward reflexes;
- selective correction from broad overwriting;
- compositional reuse of subskills from trajectory memorization;
- reopening when a formerly reliable skill stops working.

This gate is important because a world model that cannot develop efficient competence is not yet an adequate persistent agent.

## Gate 6 — embodiment: wholes, persistence, space, and self/world structure

Question:

> Can Noema learn useful organization of a continuous sensorimotor world without being handed the target identities it is credited with learning?

Only after earlier epistemic/continual-learning basics survive should the project increase perceptual complexity substantially.

Candidate tests include:

- feature binding / candidate-whole formation without privileged object records;
- persistence through occlusion and partial feature change without stable environment IDs;
- egocentric-to-allocentric spatial organization without privileged world coordinates;
- sensorimotor contingency;
- body-schema discovery under tools, detachable extensions, remote actuators, and misleading controllability;
- revisable self/world boundaries rather than a binary innate self label.

The transducer ledger determines which lower-level perceptual achievements can legitimately be claimed.

## Gate 7 — continual abstraction and compositional transfer

Question:

> Can learned structure be recombined and reused outside the surface conditions in which it was acquired?

Required evidence should include:

- novel combinations of familiar components;
- relation transfer across changed participants/modalities/surface features;
- higher-order dependencies that defeat pairwise shortcuts;
- analogy-like mapping across superficially dissimilar situations;
- intervention or counterfactual tests showing that transferred structure changes prediction/action rather than merely decoding similarly.

Explicit graph/operator machinery earns itself only if it creates measurable advantage over fair distributed alternatives.

## Gate 8 — other agents, source modeling, and nested information states

Question:

> Can Noema learn that different agents have different histories, information, reliability, and action-generating states without receiving an innate social ontology as the answer?

Required evidence includes:

- distinguishing persistent individuals without stable learner-visible IDs;
- source-specific reliability that varies by context;
- false-belief style situations where another agent acts from information Noema knows is outdated;
- deception or strategic behavior where surface cues become conditional on interaction history;
- nested modeling sufficient to predict behavior better than a surface stochastic model;
- transfer to unfamiliar agents.

This is where agent modeling must prove it is more than complicated physics when that distinction is behaviorally useful.

## Gate 9 — grounded communication with Patrick and other agents

Question:

> Can communication become causally grounded in shared world/history rather than merely statistically fluent?

Use the existing communication developmental program and console information boundary.

Required evidence includes:

- recurring signal participation;
- situated reference;
- correction/repair;
- compositional novel use;
- pragmatic and speaker-specific adaptation;
- source/testimony separation from direct observation;
- clarification when interpretation ambiguity matters;
- collaborative inquiry;
- conversational continuity across delays and changing beliefs.

Fluency alone is never sufficient.

Typed text may be used as a supplied transducer while keeping semantic grounding as the tested capability. Acoustic speech perception can be a separate later test.

## Gate 10 — valuation, learned concerns, commitment, and initiative

Question:

> Can action-relevant concerns develop from experience without collapsing belief into desire or reducing mature behavior to one fixed designer reward table?

This gate should compare motivational regimes rather than assuming cognitive self-preservation is required.

Required evidence includes:

- persistent learned preferences that generalize beyond exact rewarded examples;
- trade-offs across short/long horizons;
- commitments that survive transient pressure but remain revisable;
- self-generated projects or goals whose exact terminal state was not directly rewarded;
- targeted information seeking when uncertainty matters;
- willingness to abandon or revise goals when their learned basis changes;
- epistemic/conative firewall tests where the desired hypothesis is false.

Operational runtime integrity remains distinct from motivational concern unless explicitly included as an experimental prior.

## Gate 11 — metacognitive control and learning-to-learn

Question:

> Can Noema improve how it allocates cognition, learns, investigates, and corrects itself without requiring an externally scripted meta-policy for each situation?

Required evidence includes:

- learning which uncertainties deserve more/less computation;
- improving evidence-gathering strategy across analogous but non-identical worlds;
- changing generalization speed by context after repeated errors;
- detecting when its proposal/search strategy itself is failing;
- reopening mature structures after calibration/transfer/intervention failures;
- preserving useful prior meta-strategies where the old regime still applies.

A frozen-meta-policy ablation should lose some of the claimed learning-to-learn advantage.

## Gate 12 — integrated developmental lifetime

Question:

> Do the capabilities survive when they must coexist for a long time rather than being demonstrated one at a time?

This is not just a larger benchmark.

A serious integrated run should contain:

- nonstationary world structure;
- multiple agents;
- communication;
- long delays;
- learned skills;
- memory pressure and forgetting;
- conflicting concerns;
- interruptions;
- ambiguous and misleading evidence;
- novel combinations;
- periods without Patrick;
- opportunities for initiative;
- old beliefs that become wrong;
- tasks whose solutions were never directly demonstrated.

The system should not receive resets at every evaluator-defined task boundary.

Primary evidence becomes developmental trajectory: what was acquired, retained, revised, transferred, forgotten, relearned, and self-initiated over time.

## Cross-gate kill rules

The project should materially revise its architecture direction when any candidate repeatedly requires one of the following to pass:

- semantic target-specific proposal rules;
- privileged evaluator labels or entity identities;
- resets/batch retraining where continual adaptation is the capability under test;
- unbounded search or memory;
- a pretrained semantic system that already contains the developmental achievement being claimed;
- architecture-specific scoring that rejects behaviorally superior simpler alternatives;
- direct desirability-to-belief updates;
- intervention by Patrick as a hidden truth-write channel;
- rescue patches that solve only the current benchmark and fail transfer/negative controls.

## Roadmap is not a one-way ladder

A later stage may expose that an earlier passing mechanism was insufficient or misleading.

When that happens:

- reopen the affected requirement;
- preserve the earlier empirical result at its original narrow scope;
- do not retroactively claim the earlier test was worthless;
- do not protect the old mechanism merely because later work depends on it.

Capabilities can co-develop in the eventual system even though the evaluator isolates them for scientific clarity.

## Current frontier

The project now has enough mechanism brainstorming to stop adding architecture merely for completeness.

The next useful work is to use this roadmap to decide which **smallest serious falsification package** should become the first reviewed implementation specification after the broader design is approved.

The present best candidate remains the early persistent-learning baseline followed by Experiment A, because it can invalidate expensive epistemic machinery before the project builds the 3D organism around it.

No implementation is authorized by this roadmap alone.
