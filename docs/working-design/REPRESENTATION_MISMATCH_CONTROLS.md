# Noema representation-mismatch controls

Status: **BRAINSTORMING / NEGATIVE-CONTROL DESIGN / NOT IMPLEMENTED**

## Why these controls are necessary

The first Experiment A ambiguity world is deliberately graph-friendly. A sparse dependency representation is therefore unusually well matched to the evaluator's hidden construction.

If the bounded EGSS candidate wins only in worlds that look like the representation we gave it, that is weak evidence for a general cognitive substrate.

The experimental program should therefore include **representation-mismatch controls** before interpreting a graph-like candidate win as architectural validation.

These controls do not need to replace Experiment A's clean chain/fork falsifier. They test whether the candidate can decline, revise, or bypass explicit graph-like structure when that representation is not useful.

## Control 1 — symmetric constraint world

Generate several continuous channels constrained by a relation such as a noisy low-dimensional manifold where no single observed channel has a privileged directional role.

Example evaluator construction in spirit:

`x + y + z ≈ 0`

with symmetric generation/noise and no stable directional intervention pattern that uniquely privileges one observed variable as parent.

### Desired behavior

The learner may represent the regularity as:

- distributed continuous structure;
- a latent process/constraint;
- another reusable representation.

It should not become confidently committed to one arbitrary directed orientation merely because its explicit layer is graph-like.

### Failure

A candidate fails this control if it repeatedly invents directional ontology that adds no predictive/intervention/transfer value and then resists correction.

## Control 2 — higher-order synergy world

Construct a dependency whose predictive value appears only jointly across several channels and is weak or absent pairwise.

The exact implementation may be continuous nonlinear rather than literal binary XOR, but it should preserve the key property:

> pairwise dependency tests are insufficient to discover the useful structure.

### Desired behavior

The continuous layer or EGSS proposal mechanism should detect that a higher-order interaction improves prediction and transfer.

### Failure

If proposal localization is fundamentally pairwise, the learner should fail here. That is useful evidence that the structure grammar is too weak.

## Control 3 — regime-change world

A relationship that is initially stable changes after a long period.

The change is not announced by a semantic mode label.

### Desired behavior

The learner should accumulate anomaly evidence, reopen stale consolidated structure, and either revise temporal/conditional scope or branch a new regime representation.

### Failure

If consolidation makes the earlier structure effectively permanent, the candidate is too rigid for continual learning.

## Comparison principle

The continuous-only baseline is allowed to outperform the explicit candidate on some mismatch controls.

That is not automatically a failure.

A healthy hybrid should be capable of **not using explicit structure when explicit structure does not earn its cost**.

The serious failure is forcing every phenomenon into the candidate's favored representation and then treating representation-induced error as evidence about the world.

## Consequence for Experiment A claims

Passing the chain/fork world can support a narrow claim:

> bounded explicit structure can help preserve/revise reusable dependencies under controlled interventional ambiguity.

It cannot by itself support:

> Noema's mature world model should fundamentally be a sparse directed graph.

The mismatch controls are an early defense against accidentally converting a useful test scaffold into a hidden ontology.

## Consequence for later development

If a graph-like first candidate passes A but fails the mismatch controls, the appropriate response is not to teach it more graph templates.

The response is to broaden or replace the representation/search mechanism before scaling toward 3D embodiment, social cognition, or grounded communication.
